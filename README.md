# ECG Analysis — настольное приложение анализа ЭКГ

Автоматизация анализа суточных/разовых ЭКГ-обследований: приложение-«watcher» отслеживает папку с XML-выгрузками из электрокардиографа, конвертирует сигнал в web-интерфейс (Flask + pywebview, нативное окно + иконка трея), прогоняет сигнал через нейросети (PyTorch/fastai), формирует интерактивный отчёт и автоматически экспортирует готовые PDF-документы.

## Возможности

- **Папка-наблюдение (watcher)**: новые XML-файлы подхватываются автоматически, состояние сессий сохраняется между запусками (`.session_state.json`).
- **Классификация на DenseNet121** (PyTorch + fastai): мульти-классовая разметка отведений (две обученные модели в `models/`, ~18 МБ каждая); отдельный классификатор ритма.
- **Визуализация сигнала**: интерактивный просмотр ЭКГ (Plotly), тематические плашки-пояснения по находкам.
- **Объясняемость**: тематические текстовые плашки-пояснения (i18n на русском — `i18n/ru`).
- **PDF-отчёт**: генерация через ReportLab.
- **Экспорт PDF**: выбор папки назначения из интерфейса.
- **Десктоп-оболочка**: pywebview-окно + tray (pystray), автозапуск браузера опционально.
- **Сборка в один exe**: PyInstaller (`ECG_Analysis.spec`, инструкция в `BUILD_EXE_CPU.md`, CPU-сборка).

## Запуск (dev-режим)

```bash
pip install -r requirements.txt
python run.py
```

После старта — открывается окно приложения (Flask на `127.0.0.1:5000`).

Подробнее о внутренней архитектуре — `CHANGES.md`, `PLAN_ORIGINAL_FILES.md`.

## Сборка exe

```bash
pyinstaller ECG_Analysis.spec
```

Замечания: сборка CPU-варианта описана в `BUILD_EXE_CPU.md`; для frozen-версии папка uploads берётся из `%LOCALAPPDATA%/ECG_Analysis/uploads`.

## Состав репозитория

```
app/              Flask-приложение: routes (analysis/export/session/upload/watcher), services (модели, preprocessor, report, watcher, session store, xml parser)
app/static, app/templates   UI (JS/CSS/шаблоны)
desktop/          Лаунчер: pywebview-окно + tray
models/           Пайл-файлы моделей (DenseNet121 multiclass + вариант) — .pt
i18n/ru/          Русские тексты плашек/подсказок
utils/            Обработкой/вывод сигналов, пример XML-выгрузки
ECG_Analysis.spec Конфигурация PyInstaller
```
